# ТехноГрад — лендинг магазина техники

Одностраничный корпоративный сайт магазина техники для дома и офиса. Чистый HTML/CSS/JS, без зависимостей.

## Структура
- `index.html` — вся страница
- `img/` — фото товаров для каталога

## Запуск локально
Просто откройте `index.html` в браузере.

## Публикация
Сайт доступен через GitHub Pages: https://zafarovpolat.github.io/landing/
